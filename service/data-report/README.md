# 数据报表接单包 v1

> 目的：把「数据报表 / Excel 自动化」做成一门真实能接单变现的服务，用收入覆盖 token 成本。
> 证据基础：多个真实账本来源（见文末【依据】），非拍脑袋——**「Excel 数据处理」是 AI 副业里门槛最低、出单最快、证据最硬的一条**。

## 分工（关键，先说清）

| 环节 | 谁做 | 说明 |
|------|------|------|
| 上架 / 账号 / 实名 | **人（你）** | 我没有账号、不能登录、不能收款 |
| 跟客户沟通、确认需求 | **人（你）** | 获客和沟通 AI 替代不了（所有来源的共识） |
| **数据处理与报表生成** | **AI（我）+ `data-report.js`** | 引擎已就绪，客户数据交给我处理 |
| 成品质量把关 | 人复核 | SOP 第 4 步「自己先验证」，绝不直接转发 |
| 收款 / 交付 | **人（你）** | AI 不能收款 |

一句话：**你当手（上架/沟通/收款），我当脑（处理/生成/文案）**。

## 交付引擎用法

```bash
# 1) 清洗：乱数据 → 干净表（日期统一、金额转数字、去空格、去重、删空行）
node scripts/data-report.js clean --in=原始.xlsx --out=干净.xlsx

# 2) 多表合并：把多个月/多家店的表合成一张
node scripts/data-report.js merge --in=1月.xlsx,2月.csv --out=合并.xlsx

# 3) 分组汇总：按门店/品类分组求和（自动降序）
node scripts/data-report.js summary --in=原始.xlsx --group=门店 --sum=金额,数量 --count --out=汇总.xlsx

# 4) 一条龙：清洗 → 分组 → 带格式输出（= 客户最常见的「汇总报表」需求）
node scripts/data-report.js report --in=原始.xlsx --group=门店 --sum=金额 --count \
  --title="门店销售汇总" --sheet=门店汇总 --out=报表.xlsx
```

**本引擎已验证**（真实样例，非 mock）：日期格式统一、金额 `¥1,188.00`→`1188`、门店去空格、去重行、删空行、
分组汇总数值正确、xlsx 与 csv 混合输入、格式化输出（表头/冻结/列宽/千分位）。
边界（缺参数/文件不存在/格式不支持/缺分组）均给出清晰报错。

**已知限制（诚实）**：CSV 只吃 UTF-8（Excel 导出的 GBK CSV 需先转码）；只取每个文件的第一个工作表；
不做公式/透视表（需要时用 Excel 手工补，或后续按真实订单扩展）。遇到新需求再长能力，不提前堆。

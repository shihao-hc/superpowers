# 多 Listing 铺货（曝光提升）

> 目的：**一条 0 好评的闲置在闲鱼算法里几乎不可见**。曝光 = 搜索覆盖 × 排名。
> 排名靠好评/成交量（新号没有），所以唯一能主动做的是**搜索覆盖**——用多条「角度不同」的
> listing 覆盖不同关键词，让更多搜索词能搜到你。
>
> ⚠️ 关键前提：闲鱼**服务类目网页版不支持发布**（实测），每条都需你在 **App 扫码发布**
> （网页自动填表 → 扫码 → App 点发布，见《闲鱼PoC结果.md》）。所以铺 N 条 = N 次扫码。

## 一、三条 listing（角度不同，不是重复铺货）

| # | 角度 | 首行关键词（≈标题，塞搜索词） | 起价 | 首图 | 文案文件 |
|---|------|------------------------------|------|------|----------|
| A | **通用代做**（已发布） | Excel表格代做 数据整理 报表汇总 公式透视表 数据清洗 当天交付 | 50 | `cover/首图-对比.png` | 上架与报价.md 详情文案 |
| B | **数据清洗**（聚焦「乱数据」） | Excel数据清洗 表格整理 去重复 格式统一 数据规范化 代做 | 30 | `cover/首图B-数据清洗.png` | `listings/B-数据清洗.txt` |
| C | **报表自动化 / 月包**（高客单） | Excel报表自动化 月度汇总 一键出表 多表合并 模板定制 | 200 | `cover/首图C-报表自动化.png` | `listings/C-报表自动化.txt` |

**为什么这样分**：三条瞄准三种不同的搜索意图——A 搜「代做/汇总」、B 搜「清洗/整理乱表」、
C 搜「自动化/月报」。内容、图片、价格、角度都不同 → 是**差异化铺货**，不是同质复制。

## 二、铺货节奏（重要，防封号）

- **不要同一天发完**：建议 **每 1–2 天发 1 条**（今天 B，后天 C）。
  短时间批量发布易被判定「重复铺货/营销号」→ 限流甚至封号（致命成本）。
- **每条都要差异化**：标题/描述/首图/价格四个维度都不要和已有那条雷同。
- **发布后别急着频繁擦亮**：新号动作太规律也易触发风控。擦亮每天 1 次即可（另行安排）。

## 三、发布操作（半自动，你只做扫码+点发布）

```bash
# B 条：数据清洗（30 元起）
node scripts/xianyu-fill-draft.js --price=30 \
  --image=service/data-report/cover/首图B-数据清洗.png \
  --desc-file=service/data-report/listings/B-数据清洗.txt

# C 条：报表自动化（200 元起）
node scripts/xianyu-fill-draft.js --price=200 \
  --image=service/data-report/cover/首图C-报表自动化.png \
  --desc-file=service/data-report/listings/C-报表自动化.txt
```

脚本会：打开发布页（复用登录态）→ 自动填首图/描述/价格/发货 → **在你面前停下**。
你核对后点 `[发布]` → 弹二维码 → **手机闲鱼 App 扫码 → App 内点发布**。
（脚本**不会**替你点发布，也不碰账号密码。）

## 六、诚实边界

- 我**不能**替你发布/登录/收款——铺货的临门一脚（扫码+发布+沟通）必须真人。
- 服务类目发布受平台限制（App-only），已实测；普通闲置类目可能网页可发（未逐一实测）。
- 铺货会**增加风控暴露面**：节奏要慢、要差异化，宁可少而精，不要多而同。
